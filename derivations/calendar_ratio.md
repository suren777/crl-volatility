# Ratio form of the band derivative: dC/du = T1 (1 + Q) (epic 0016, task 08-ratio)

Status: partial. The exact identity, the rho = 0 case and a Cauchy-Schwarz inequality are proved
below; the numerical picture is from `calendar_ratio.py`. No analytic bound B < 1 on any
region was established, and no computer-assisted box certificate was attempted, so the claim
1 + Q > 0 on the band is supported by numerics only.

## Identity (PROVED, with one standard interchange)

Notation as in `calendar_band.md`: F = D = 1, u = sqrt(tau Q), s^2 = ln(1+k^2),
zeta = e^{sZ - s^2/2}, y = u^2 zeta, x = ln K. Let M = exp(rho sqrt(y) Z - rho^2 y/2),
m = E[M] (Z ~ N(0,1)), A = M/m, so E[A] = 1 and A is the density of the tilted law P^A.
Let h = d(ln M)/du = rho sqrt(zeta) Z - rho^2 u zeta; differentiating m gives E^A[h] = m'/m.
Conditionally on Z, S is lognormal with forward F_Z = A and total variance v = (1 - rho^2) y,
which reproduces P(S > x) = E_Z[N(d2)] of `calendar_band.md`. So C = E[c(Z)] with

    c = F_Z N(d1) - e^x N(d2),   d1 = (ln F_Z - x + v/2)/sqrt(v),   d2 = d1 - sqrt(v).

Black partials: dc/dF = N(d1) and dc/dv = F_Z phi(d1)/(2 sqrt(v)). Also d F_Z/du = F_Z (h - m'/m),
dv/du = 2u(1 - rho^2) zeta and sqrt(v) = u sqrt((1 - rho^2) zeta), so dv/du / (2 sqrt v) = sigma
with sigma = sqrt((1 - rho^2) zeta). Hence, pointwise in Z,

    dc/du = F_Z N(d1) (h - m'/m) + F_Z phi(d1) sigma.

Taking expectations (E[F_Z g] = E^A[g]) gives

    dC/du = T1 + Cov_A(N(d1), h),   T1 = E^A[phi(d1) sigma] > 0,

using E^A[h] = m'/m. Dividing by T1 > 0:

    dC/du = T1 (1 + Q),   Q = Cov_A(N(d1), h) / T1.

The pointwise identity is checked symbolically in `test_calendar_ratio.py`
(VERIFIED SYMBOLICALLY, exact rational values). The interchange of d/du and E is the usual
differentiation under the integral; I did not write out a dominating function, and it is
checked numerically by the central-difference tests (VERIFIED NUMERICALLY, below).

## Proved facts

- rho = 0: h = 0 and M = 1, so Q = 0 and dC/du = T1 > 0 (mixture of Black vegas).
- Cauchy-Schwarz (PROVED): since 0 <= N(d1) <= 1, sd^A(N(d1)) <= 1/2, so
  |Q| <= sd^A(N(d1)) sd^A(h) / T1 <= sd^A(h) / (2 T1). A bound B < 1 would follow from a lower
  bound on T1 relative to sd^A(h) on an explicit region. I did not prove such a bound. The
  numerics below show T1 can be far smaller than |Cov| at large u with small k (where C is
  numerically saturated), so this route does not close without further work.

## Not established

- No analytic bound |Q| <= B(u, k, rho, x) with B < 1 on any region (goal 2 not met).
- No computer-assisted certificate for 1 + Q > 0 on boxes (goal 3 not attempted).
- The numbers below are float64 pointwise evaluations on a 25-point x-grid per parameter
  point, not a minimum over the continuum, and not proofs.
- Conditioning: where C is numerically saturated, dC/du is below float64 resolution and
  Q is not resolved. The script flags such points (n_res counts resolved x per parameter
  point) and excludes them from every minimum. Resolution means |Cov| >= 1e-8 of the sum of
  absolute integrand terms. The resolved values were checked against 60-digit mpmath
  (`test_float_ratio_matches_high_precision` checks one band point; a few more resolved points
were checked by hand during the work and agreed to about nine digits).
- Asymptotic trend: the minimum over the ladder decreases slowly in u. Whether it stays
  positive for all u is not established.
